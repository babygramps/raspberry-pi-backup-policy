Raspberry Pi Backups privacy policy

Updated November 7, 2026. Raspberry Pi Backups is a personal utility operated by Richard Rothbart for his own devices and Google account. It is not a public backup service.

Data and Google Drive access

The utility reads selected local files and application databases, encrypts them using Restic, and uploads the encrypted backup repository to the owner's Google Drive. It reads Drive file metadata and backup contents to locate, verify, and restore backups, and removes expired backup snapshots according to the configured retention policy.

The Google authorization requests Drive read/write access because it must access an existing backup repository. This permission is broader than a single folder. The backup configuration targets the designated backup repository; the utility does not intentionally process unrelated Drive documents.

Storage and security

Backup contents are encrypted before upload. Google stores the encrypted repository. OAuth credentials and the backup encryption password are stored in restricted files on owner-controlled devices. The password is needed to restore backup contents. Temporary database copies are used to create consistent backups.

Use and sharing

The utility uses Google user data only to provide backup and recovery for the owner. It does not sell backup content, use it for advertising, or use it to train AI models. Backup content is not published on this website or shared with other users by the utility.

The utility's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls the retention schedule and can delete the backup repository in Google Drive. Removing Drive files may move them to Drive's Trash until the owner or Google removes them. Revoking the connection in Google Account connections stops future access but does not delete existing backups.

This website and contact

This informational website is hosted by GitHub Pages, which may process standard web-request information under GitHub's privacy policy. It does not receive backup contents or credentials and contains no advertising or analytics scripts.

For questions, contact the operator through the operator's GitHub profile.
