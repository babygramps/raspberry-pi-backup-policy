Raspberry Pi Backups

A personal backup utility operated by Richard Rothbart. It uses Restic and rclone to save encrypted backups from the owner's Raspberry Pi to the owner's Google Drive.

The utility supports scheduled backups, recovery of files and application data, and retention of previous versions. It is for the owner's personal use and does not offer public registration.

This website contains application information only. Backup files and credentials are not hosted here.
